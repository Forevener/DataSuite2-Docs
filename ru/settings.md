# Настройки

Нажмите кнопку **Настройки** (значок гаечного ключа) на верхней панели, чтобы открыть панель настроек. Панель содержит боковое меню для быстрой навигации между разделами. Изменения вступают в силу немедленно — существующие результаты на странице обновляются в реальном времени. Все настройки сохраняются в браузере и автоматически восстанавливаются при следующем посещении.

Кнопки **Экспорт** и **Импорт** позволяют сохранить настройки в JSON-файл или загрузить их из файла. Это удобно для обмена конфигурациями с коллегами или переноса настроек между устройствами. Кнопка **Сбросить настройки** восстанавливает все параметры по умолчанию.

Изменённые настройки подсвечиваются фоном, а разделы с изменениями отмечаются точкой-индикатором в боковом меню.

## Отображение
### Язык

Выберите язык интерфейса из списка доступных. При первом посещении DataSuite определяет язык браузера и выбирает наиболее подходящий.

### Режим точности

Управляет способом округления чисел во всех результатах:

- **Десятичные знаки** — фиксированное количество цифр после запятой (по умолчанию)
- **Значащие цифры (только дробная часть)** — считает значащие цифры только в дробной части; целая часть сохраняется полностью. Сохраняет малые значения (например, 0.00312 остаётся с 3 цифрами), не округляя крупные числа неожиданно.
- **Значащие цифры** — считает значащие цифры от первой ненулевой цифры. Стандарт в естественных науках.

### Настройки точности

Три отдельных параметра точности для разных типов вывода:

- **Описательные статистики и проценты** (по умолчанию: 2) — средние, медианы, стандартные отклонения, асимметрия, эксцесс, пропорции, доля объяснённой дисперсии
- **Статистики и коэффициенты** (по умолчанию: 3) — статистики критериев (t, F, W, χ²), размеры эффекта (d Коэна, r, η²), регрессионные коэффициенты, факторные нагрузки, индексы соответствия, доверительные интервалы
- **P-значения** (по умолчанию: 3) — все p-значения при выборе точного формата

### Другие параметры отображения

- **Экспоненциальная нотация** — при включении очень большие или очень малые числа отображаются в научной нотации (например, 1.23e-5).
- **Автопрокрутка** — при включении страница автоматически прокручивается к новому результату после анализа.

## Статистика
### Уровень доверия

Задаёт уровень доверия для всех анализов, в которых вычисляются доверительные интервалы: 90%, 95% (по умолчанию), 99% или 99.9%.

### Итерации бутстрепа

Число итераций для расчётов на основе бутстрепа. Диапазон: 10–10 000. По умолчанию: 100. Более высокие значения дают более стабильные оценки, но требуют больше времени.

### Уровень значимости для проверки допущений

Пороговый уровень α для тестов допущений (нормальность, однородность дисперсий, сферичность и т.д.). По умолчанию: 0.05. Этот параметр отделён от основного уровня значимости, поскольку тесты допущений решают обратную задачу — более высокий α (например, 0.10) является *более* консервативным, выявляя больше нарушений.

### Статистические пороги

Настраиваемые пороговые значения для интерпретации результатов. Каждый набор порогов имеет именованные уровни:

**Пороги коллинеарности VIF** — для выявления мультиколлинеарности в регрессионном анализе:
- Умеренная (по умолчанию: 5), Высокая (по умолчанию: 10)

**Пороги соответствия модели** — для интерпретации индексов соответствия в факторном анализе и КФА:
- RMSEA: Отличное (0.05), Приемлемое (0.08), Плохое (0.10)
- CFI: Отличное (0.95), Приемлемое (0.90)
- TLI: Отличное (0.95), Приемлемое (0.90)
- SRMR: Отличное (0.05), Приемлемое (0.08), Плохое (0.10)

> Распространённые альтернативы: Hu & Bentler (1999) предлагают более строгие пороги (RMSEA < 0.06, CFI/TLI > 0.95, SRMR < 0.08). В некоторых областях используются более мягкие пороги (RMSEA < 0.08 как приемлемое, CFI > 0.90). Настройте их в соответствии с конвенциями вашей дисциплины.

**Шкала силы корреляции** — для интерпретации коэффициентов корреляции:
- Очень сильная (0.9), Сильная (0.7), Умеренная (0.5), Слабая (0.3), Очень слабая (0.1)

> Эти значения следуют конвенциям Коэна (1988), широко используемым в психологии. В медицинских и естественных науках часто применяются другие шкалы. Evans (1996) предлагает: 0.20–0.39 (слабая), 0.40–0.59 (умеренная), 0.60–0.79 (сильная), 0.80+ (очень сильная).

## Настройки p-значений
### Формат отображения

- **Точное значение** — показывает вычисленное p-значение (например, 0.0312)
- **Категория** — показывает пороговую метку (например, «p < 0.05»)
- **Скрыто** — p-значения не отображаются

### Поправка на множественную проверку

При одновременном проведении множества тестов p-значения можно скорректировать для контроля ложноположительных результатов. Выберите метод:

- Нет (по умолчанию)
- Бонферрони
- Холма
- Хоммеля
- Хохберга
- Бенджамини–Хохберга (FDR)
- Бенджамини–Йекутиели (FDR)

Можно отображать исходные и скорректированные значения рядом или заменить исходные скорректированными.

> **Какой метод выбрать?** Бонферрони — наиболее консервативный: минимизирует ложноположительные результаты, но может скрыть реальные эффекты. Метод Холма строго мощнее Бонферрони при тех же гарантиях, поэтому предпочтительнее. Бенджамини–Хохберга (FDR) — популярный компромисс: контролирует *долю* ложных открытий, а не исключает их полностью, что удобнее для поисковых исследований. При сомнениях Холм или Бенджамини–Хохберга — хорошие варианты по умолчанию.

### Уровень значимости

Пороговый уровень α для определения значимости (по умолчанию: 0.05). Управляет тем, при каком p-значении результаты считаются значимыми.

### Форматирование значимости

Параметры можно комбинировать:

- **Полужирные значимые p-значения** — значимые p-значения выделяются полужирным начертанием
- **Окрашивание значимых p-значений** — значимые p-значения окрашиваются (цвет задаётся через hex-код и палитру)
- **Подсветка значимых p-значений** — значимые ячейки подсвечиваются фоном (включено по умолчанию; цвет настраивается)
- **Звёздочки значимости** — к статистикам критериев добавляются звёздочки (\*, \*\*, \*\*\*) в соответствии с уровнем значимости
- **Столбец интерпретации** — в таблицы результатов добавляется столбец с текстовым заключением

## Внешний вид
### Стиль таблиц

Пять вариантов оформления таблиц результатов:

| Стиль | Описание |
|---|---|
| Полные границы | Все ячейки с рамкой (по умолчанию) |
| Стиль APA | Толстые линии сверху и снизу, разделитель заголовка, без рамок ячеек |
| Без границ | Без рамок, кроме лёгкого разделителя заголовка |
| Горизонтальные линии | Горизонтальные линии между всеми строками |
| Минимальный | Только верхняя, нижняя и заголовочная линии |

### Шрифт

- **Гарнитура** — системная по умолчанию, Arial, Times New Roman, Courier New, Georgia или Verdana.
- **Размер шрифта** — системный по умолчанию или фиксированный (10–18 пт).

Настройки применяются только к разделу вывода — остальной интерфейс сохраняет стандартный вид.

## Пропущенные данные
### Метод

- **Попарное удаление** (по умолчанию) — наблюдения исключаются только при наличии пропущенных значений в конкретных анализируемых переменных. Максимизирует объём доступных данных для каждого расчёта.
- **Построчное удаление** — исключаются любые наблюдения с пропущенным значением хотя бы по одной из выбранных переменных. Гарантирует, что все анализы выполняются на одном и том же подмножестве полных наблюдений.
- **Импутация** — пропущенные значения заменяются вычисленными заменителями.

### Параметры импутации

При выборе импутации задайте стратегию замены:

- **Среднее** — только для числовых переменных; заменяет пропуски средним значением переменной
- **Медиана** — только для числовых переменных; заменяет медианой
- **Мода** — заменяет наиболее часто встречающимся значением (подходит как для числовых, так и для категориальных переменных)
- **Константа** — заменяет фиксированным значением, которое вы указываете

Обработка пропущенных данных применяется глобально и одинаково влияет на все анализы. Также можно вручную исключать наблюдения с помощью [фильтра наблюдений](./getting-started.md#фильтрация-наблюдений).

## Графики
### Цвета тепловой карты

Три цвета управляют градиентом в корреляционных тепловых картах и аналогичных визуализациях:

- **Верхний цвет** (по умолчанию: красный #b2182b) — положительный экстремум
- **Средний цвет** (по умолчанию: светло-серый #f7f7f7) — нейтральный центр
- **Нижний цвет** (по умолчанию: синий #2166ac) — отрицательный экстремум

### Максимальный интервал между точками

Управляет максимальным расстоянием в пикселях между точками данных в линейных графиках (по умолчанию: 40 пкс). Меньшие значения дают более плотные, гладкие кривые; большие — более разреженный вывод.

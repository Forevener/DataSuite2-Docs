# Руководство по подсчёту баллов по опросникам

В руководстве разобраны три реальных сценария подсчёта баллов — от простого к сложному. Каждый из них опирается на возможности [преобразования данных](./data-transformation.md), поэтому рекомендуется сначала ознакомиться с той страницей.

Типичная отправная точка: есть таблица (например, из Google Forms), где каждая строка — участник, а каждый столбец — пункт опросника. Ответы могут быть текстовыми («Полностью согласен») или уже числовыми — в любом случае для анализа нужны шкальные оценки.

## Пример 1: PHQ-9 (простая сумма)

[PHQ-9](https://en.wikipedia.org/wiki/PHQ-9) — инструмент скрининга депрессии из 9 пунктов. Каждый пункт спрашивает, как часто за последние две недели наблюдался тот или иной симптом. Обратных пунктов нет — нужно лишь перекодировать и просуммировать ответы.

**Варианты ответов:** Совсем нет (0), Несколько дней (1), Больше половины дней (2), Почти каждый день (3). Диапазон суммарного балла: 0–27.

### Шаг 1: перекодирование текста в числа

Если данные уже содержат числа от 0 до 3, этот шаг можно пропустить.

1. Откройте раздел **Преобразование данных** и нажмите **+ Перекодировка значений**
2. На левой панели выберите все 9 пунктов PHQ
3. Редактор автоматически заполнит уникальные текстовые значения. Задайте соответствие:

| Исходное значение | Новое значение |
|---|---|
| Совсем нет | 0 |
| Несколько дней | 1 |
| Больше половины дней | 2 |
| Почти каждый день | 3 |

4. В параметрах вывода выберите **Заменить исходные значения** — текст больше не нужен
5. Дайте правилу название (например, «PHQ-9 перекодирование») и нажмите **Сохранить правило**

### Шаг 2: вычисление суммарного балла

1. Нажмите **+ Формула**
2. Выберите те же 9 пунктов в качестве входных переменных
3. Введите формулу:

```
sum(v1:v9)
```

4. В параметрах вывода выберите **Создать новые переменные** и назовите переменную `PHQ9_Итог`
5. Сохраните правило

Готово. В данных появится столбец `PHQ9_Итог` со значениями от 0 до 27.

## Пример 2: Шкала самооценки Розенберга (пункты с разными направлениями)

[Шкала самооценки Розенберга](https://en.wikipedia.org/wiki/Rosenberg_self-esteem_scale) состоит из 10 пунктов с четырёхбалльной шкалой. Пункты 3, 5, 8, 9 и 10 имеют обратные формулировки и перед суммированием требуют разворота.

**Варианты ответов:** Полностью согласен (3), Согласен (2), Не согласен (1), Полностью не согласен (0). Диапазон суммарного балла: 0–30.

### Вариант А: разворот при подсчёте (рекомендуется)

Этот вариант сохраняет исходные значения пунктов без изменений — шаг перекодирования не нужен. Инверсия происходит прямо внутри формулы по схеме `(макс - пункт)`, где макс равен 3 для шкалы 0–3:

1. Нажмите **+ Формула**
2. Выберите все 10 пунктов ШСР в качестве входных переменных (по порядку)
3. Введите формулу:

```
v1 + v2 + (3-v3) + v4 + (3-v5) + v6 + v7 + (3-v8) + (3-v9) + (3-v10)
```

4. Создайте новую переменную `RSE_Итог`
5. Сохраните правило

Инвертируемые пункты (v3, v5, v8, v9, v10) переворачиваются «на лету»: ответ 0 становится 3, 1 становится 2, и так далее. Исходные данные остаются неизменными, что упрощает последующую проверку отдельных пунктов.

### Вариант Б: перекодирование, затем суммирование

Если нужно явно сохранить инвертированные значения в данных:

1. **+ Перекодирование значений** — выберите только 5 инвертируемых пунктов (3, 5, 8, 9, 10). Задайте соответствие: 0→3, 1→2, 2→1, 3→0. Выберите **Заменить исходные значения**.
2. **+ Формула** — выберите все 10 пунктов. Формула: `sum(v1:v10)`. Создайте новую переменную `RSE_Total`.

Оба варианта дают одинаковый результат. Вариант А компактнее; вариант Б оставляет инвертированные значения видимыми в таблице данных.

## Пример 3: TIPI — Ten-Item Personality Inventory (несколько субшкал)

[TIPI](https://gosling.psy.utexas.edu/scales-weve-developed/ten-item-personality-measure-tipi/) измеряет «Большую пятёрку» черт личности с помощью 10 пунктов — по два на каждую черту, один прямой и один обратный. Шкала от 1 («Категорически не согласен») до 7 («Категорически согласен»), а каждая субшкала — это **среднее** двух её пунктов.

Структура опросника:

| Черта | Прямой пункт | Обратный пункт |
|---|---|---|
| Экстраверсия | 1. Экстравертированный, энергичный | 6. Замкнутый, тихий |
| Доброжелательность | 7. Отзывчивый, душевный | 2. Критичный, конфликтный |
| Добросовестность | 3. Надёжный, самодисциплинированный | 8. Дезорганизованный, небрежный |
| Эмоциональная стабильность | 9. Спокойный, эмоционально устойчивый | 4. Тревожный, легко расстраивающийся |
| Открытость опыту | 5. Открытый новому, сложный | 10. Консервативный, нетворческий |

### Подсчёт с помощью многопеременной формулы

Это идеальный случай для синтаксиса `@` — пять субшкал вычисляются одним правилом.

1. Нажмите **+ Формула**
2. Выберите все 10 пунктов TIPI в качестве входных переменных, в порядке пунктов (1–10)
3. Введите формулу:

```javascript
@Экстраверсия = (v1 + (8-v6)) / 2
@Доброжелательность = ((8-v2) + v7) / 2
@Добросовестность = (v3 + (8-v8)) / 2
@Эмоциональная стабильность = ((8-v4) + v9) / 2
@Открытость = (v5 + (8-v10)) / 2
```

4. Сохраните правило (параметры вывода при объявлениях `@` задаются автоматически)

Формула инверсии здесь — `(8 - пункт)`, потому что каждая субшкала принимает значения от 1 до 7.

> **Почему `(8 - v)`, а не `(7 - v)`?** Формула инверсии всегда равна `(макс + мин) - значение`. Для шкалы 1–7 это `(7 + 1) - v = 8 - v`. Для шкалы 0–3 (как в примере с ШСР) — `(3 + 0) - v = 3 - v`. Такой подход сохраняет исходный диапазон шкалы.

## Общие советы

- **Проверяйте диапазон шкалы.** Формула инверсии зависит от него: `(макс + мин) - значение`. Для шкалы Лайкерта 1–5 это `6 - v`, для 0–4 — `4 - v`, для 1–7 — `8 - v`. Все доступные функции и синтаксис приведены в [справочнике формул](./formula-reference.md).
- **По возможности сохраняйте исходные данные.** Использование встроенной инверсии (вариант А) позволяет в любой момент вернуться и проверить ответы по отдельным пунктам без путаницы с перекодированными значениями.
- **Давайте переменным понятные названия.** Используйте описательные имена — `PHQ9 Депрессия`, `RSE Самооценка`, `TIPI Экстраверсия` — они будут отображаться во всех результатах анализа.
- **Правила применяются по порядку.** Если в первом правиле текст перекодируется в числа, второе правило с формулой получит уже числовые значения. Промежуточные результаты можно проверить в [предпросмотре данных](./getting-started.md#просмотр-данных) в любой момент.
- **Сохраняйте файл проекта.** Правила преобразований сохраняются внутри файла проекта (.json), поэтому при повторном открытии проекта все правила остаются на месте. Правила также можно хранить в [библиотеке правил](./data-transformation.md#библиотека-правил) для повторного использования в других проектах.
